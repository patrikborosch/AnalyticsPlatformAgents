# output/

This folder is the **runtime target** for agent-generated deliverables.

Agents write here during workflow execution:
- `architecture-spec.md` — produced by @architect
- `fabric-blueprint.md` — produced by @modeler
- `artifacts/` — produced by @creator → @FabricDataEngineer

> **Do not commit runtime outputs to this folder.**
> For example deliverables, see [`../output_examples/`](../output_examples/).
